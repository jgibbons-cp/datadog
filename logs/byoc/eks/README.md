EKS Automated Lab
--

This lab brings up a single onde BYOC cluster on EKS.  
  
Files
--

1) ai_generated_md.md - markdown generated from AI when it created the script from a confluence page.  
  
2) cluster.yaml - template cluster config for `eksctl`.  
  
3) eks_lab_setup.md - another markdown, not sure where created.  These other markdowns may be removed.  
  
4) eks_lab_setup.sh - script to bring up the lab.  This script was generated by Claude from a step by step guide 
on a Confluence page.  From there it was tested and reworked to get the code where we wanted it.  It needs quite 
a bit of cleanup as there was just enough work done to get it running as expected.  Further cleanup is roadmap.  
  
Pre-Requisites
--

* [eskctl](https://docs.aws.amazon.com/eks/latest/userguide/getting-started-eksctl.html)  
* [kubectl](https://kubernetes.io/docs/reference/kubectl/)  
* [helm](https://helm.sh/)  
  
Usage
---

1) Configure the environment:  
  
The variables that are most likely to need changing from the default are:  
  
* export K8S_VERSION="1.36"  
* export NODE_TYPE=m5.4xlarge  
* export REGION=us-west-1  
* export NAMESPACE=byoclogs  
* \# change if not using the ese sandbox  
  export PROFILE="--profile account-admin-770341584863"  
* export SITE=datadoghq.com # us1  
* \# https://app.datadoghq.com/organization-settings/api-keys
* export DD_API_KEY=
  
2) bash eks_lab_setup.sh
